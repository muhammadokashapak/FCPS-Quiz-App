## 📌 Overview

**FCPS Pro** is a high-yield, distraction-free clinical testing platform engineered specifically to help postgraduate doctors and medical graduates master the **FCPS Part 1 (Fellow of College of Physicians and Surgeons Pakistan)** examination.

The application features timed mock test conditions, an intelligent clinical mistake reviewer, anti-cheating tab detection, and offline progress persistence using browser `localStorage` with zero backend setup required.

---

## 🌟 Key Features

- **Zen-Mode Timed Mocks:** Simulates official CPSP examination interface, removing distractions and focusing strictly on clinical vignettes and timers.
- **Strict Tab-Switch Penalty:** Switching browser tabs during an active mock test incurs a penalty to prevent cheating and simulate real exam discipline.
- **Dedicated Mistakes Bank:** Incorrectly answered questions are automatically preserved in an interactive review hub with complete medical explanations and references.
- **High-Yield Clinical Vignette Prioritization:** Prioritizes complex, multidisciplinary scenarios (Anatomy, Pathology, Pharmacology, Physiology) to maximize recall retention.
- **100% Offline & Private:** Operates entirely client-side using `localStorage`. No accounts, servers, or external tracking required.

## 🚀 Quick Start (Instant Browser Launch)

Because FCPS Pro is built as a zero-dependency modern web application:

1. Clone or download this repository:
   ```bash
   git clone https://github.com/muhammadokashapak/FCPS-Quiz-App.git
   cd FCPS-Quiz-App
   ```
2. Double-click or open `index.html` in Google Chrome, Microsoft Edge, Safari, or Mozilla Firefox.
3. Select your question batch size and start practicing immediately!

> **Hosting on GitHub Pages:**
> You can also enable **GitHub Pages** under `Settings -> Pages -> Deploy from a branch (main)` to host and access this app live online for free on any smartphone, iPad, tablet, or PC.
